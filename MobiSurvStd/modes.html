Mode comparison

Each survey uses its own list of transportation modes. The table below shows, for each MobiSurvStd mode (variables main_mode of trips and mode of legs), the original modalities that are mapped to it in each survey type. See how to read the comparison tables.

The EDGT, EDVM, and EMD surveys share the same mode definitions. The EMC² surveys use the same definitions too, except for electric bicycles, motorcycles (unspecified size), trains, taxis, and VTC, which use new or different codes.

Note that some public-transit modalities and the car / truck distinction are not fully consistent across survey types.

Notes:

  • Codes marked (undocumented) appear in the data but are not documented:
    • In EDGT / EDVM / EMD / EMC², code 34 is used in Le Havre (and possibly other surveys) and code 72 in Thionville 2012.
    • In EGT2020, codes B612 and B613 are assumed to be walking because they start with B61 (“Marche”).
    • In EMG2023, the single entry RER/METRO is assumed to be a typo for RER/TRAIN.
  • In EMP2019, codes 9999 and vide (no answer) are mapped to null.
